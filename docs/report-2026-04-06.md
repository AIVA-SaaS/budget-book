## 버그 수정 (3건)

### 1. 예산 목록 금액 불일치
- **증상**: 생활비 & 장 다른 항목인데 같은 금액 표시, 상위 총 예산과 개별 합계 불일치
- **원인**: FE `effectiveMonthlyAmount`(클라이언트 계산)와 BE `budgetAmount`(서버 계산) 간 미세한 차이
- **수정**: 예산 타일에서 BE의 `summaryItem.budgetAmount`를 표시하여 총합과 일치하도록 변경
- **파일**: `budget_list_page.dart`

### 2. 예산 수정 카테고리 표시
- **증상**: 카테고리 선택에서 "그룹 > 하위" 형태 미표시
- **원인**: `_initializeFromBudget`에서 `budget.category.name`만 저장, 그룹명 누락
- **수정**: `budget.groupName`이 있으면 "그룹 > 카테고리" 형태로 표시
- **파일**: `budget_form_page.dart:89`

### 3. 지출계획 예산 연결 주간 예산 표시
- **증상**: 주간 예산이 *4주 단일 금액으로 표시
- **수정**: 주간 예산을 주차별로 분리하여 "카테고리 — 첫째주 (4/1~4/7) — 금액원" 형태로 표시. 선택된 날짜에 해당하는 주만 선택 가능.
- **파일**: `spending_plan_form_page.dart:604-638`

## 기능 구현 (5건)

### 기능 1: 주간 예산 반복 (기간 미지정 시)
- **상태**: ✅ 이미 구현됨 (확인만 완료)
- `MonthlyBudgetRepository`의 쿼리에서 `periodType = NONE AND yearMonth <= :yearMonth` 조건으로 생성 월 이후 모든 월에 자동 포함

### 기능 2: 금액 입력 +/- 계산 및 지우기
- **상태**: ✅ 신규 구현
- `core/widgets/amount_input_field.dart` — 공통 위젯 생성
  - +/- 버튼으로 금액 증감 (다이얼로그 입력)
  - X 버튼으로 초기화
  - CurrencyInputFormatter 통합
- 적용: 거래 폼, 예산 폼, 이체 폼, 지출계획 폼

### 기능 3: 주간 예산 달 이동
- **상태**: ✅ 신규 구현
- `budget_list_page.dart` 주간 탭에 `MonthNavigator` 추가
- `WeeklyBudgetBloc`에 year/month 전달하여 다른 달 조회 가능

### 기능 4: 예산에 계획 예정액 포함
- **상태**: ✅ 신규 구현
- **BE**: `SpendingPlanRepository.sumPlannedAmountByBudget()` 쿼리 추가
  - `BudgetService.getBudgetSummary()`에서 예산별 PLANNED 상태 지출계획 금액 합산
  - `BudgetSummaryItemResponse`에 `plannedAmount` 필드 추가
  - `remainingAmount = budget - spent - planned`, `usageRate` = (spent + planned) / budget
- **FE**: `BudgetSummaryItem`에 `plannedAmount` 추가
  - 예산 타일 진행률 바: 2-color (사용=테마색, 예정=주황)
  - 텍스트: "N원 사용 + M원 예정 / 예산원"

### 기능 5: 구매 목록 기존 거래 연결
- **상태**: ✅ 신규 구현
- 완료 다이얼로그에 "새 거래 생성" / "기존 거래 연결" 토글 추가
- "기존 거래 연결" 선택 시 현재 월의 거래 목록에서 검색/선택
- 선택한 거래의 정보로 `CompletePlanResult.linkedTransactionId` 전달
- 전체 파이프라인: Dialog → Event → Bloc → Repository → DataSource → BE API

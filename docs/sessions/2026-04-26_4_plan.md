## 요청 내용

### 변경 파일

### 기술적 제약사항
- BE API 계약:
  - `PUT /budgets/{id}` body 에 `applyToFuture: bool` (BudgetUpdateRequest)
  - `DELETE /budgets/{id}?applyToFuture=true|false` (RequestParam)
- FE 데이터소스에서 두 곳 처리 분리 필요 (PUT body vs DELETE query).

# 신용카드 카드사별 결제일 프리셋 + 커스텀 기능
> 날짜: 2026-03-20 | 회차: 3 | 상태: 기획

## 요청 내용
신용카드(CREDIT) 결제수단 등록 시 카드사별 기본 결제일/마감일 프리셋을 제공하고,
사용자가 본인 카드사에 맞게 커스텀할 수 있도록 한다.

예시:
- 롯데카드: 결제일 16일, 이용기간 1일~말일
- 현대카드: 결제일 17일, 이용기간 1일~말일

## 현재 구현 상태

### BE (PaymentMethod)
- `closingDay` (마감일): 이용기간 종료일 (예: 31 = 말일)
- `settlementDay` (결제일): 대금 청구일 (예: 16)
- `calculateSettlementDate()`: closingDay 기준으로 거래가 어느 결제월에 속하는지 계산

### FE (PaymentMethodFormSheet)
- CREDIT 선택 시 마감일/결제일 직접 입력
- `_buildBillingCycleInfo()`: 입력값 기반 결제 주기 안내 표시
- 카드사 선택 기능 없음, 프리셋 없음

## 영향 범위 분석
- **변경 파일**: FE만 (BE 변경 불필요)
- BE의 `closingDay`/`settlementDay` 필드를 그대로 사용, 프리셋은 FE에서 자동 입력
- DB 스키마 변경 없음

### 상세 설계

#### 1. 카드사 프리셋 데이터 (`card_issuer_presets.dart`)
```dart
class CardIssuerPreset {
  final String id;
  final String name;       // "신한카드"
  final int settlementDay; // 14
  final int closingDay;    // 15
  final String description; // "전월 16일 ~ 당월 15일"

  const CardIssuerPreset({...});
}

const cardIssuerPresets = [

  CardIssuerPreset(id: 'kb', name: 'KB국민카드', settlementDay: 14, closingDay: 14, ...),
  // ... 10개 카드사
  CardIssuerPreset(id: 'custom', name: '직접 입력', settlementDay: 0, closingDay: 0, ...),

```

#### 2. 폼 UI 변경 (`payment_method_form_sheet.dart`)

**CREDIT 선택 시 추가되는 UI 흐름:**
```
[유형: 현금 / 체크 / 신용 / 은행]
           ↓ (신용 선택 시)
[카드사 선택] ← DropdownButton / Chip 리스트
  신한카드 | KB국민 | 삼성 | 현대 | 롯데 | 하나 | 우리 | 농협 | BC | 카카오 | 토스 | 직접입력
           ↓ (선택 시)
[결제수단 이름] ← 카드사명으로 자동 설정 (편집 가능)
[마감일: 15일] ← 프리셋에서 자동 입력 (편집 가능)
[결제일: 14일] ← 프리셋에서 자동 입력 (편집 가능)
[결제 주기 안내] ← 기존 _buildBillingCycleInfo 그대로 사용
```

**카드사 선택 UI**: `Wrap` + `ChoiceChip` (한 줄에 여러 개 표시, 스크롤 불필요)

#### 3. 자동 입력 동작

```dart
void _onCardIssuerSelected(CardIssuerPreset preset) {
  setState(() {
    _selectedIssuer = preset;
    if (preset.id != 'custom') {
      _settlementDayController.text = preset.settlementDay.toString();
      _closingDayController.text = preset.closingDay.toString();
      if (_nameController.text.isEmpty) {
        _nameController.text = preset.name;
      }
    } else {
      _settlementDayController.clear();
      _closingDayController.clear();
    }
  });
}
```

- 카드사 선택 → 결제일/마감일 자동 입력
- 이름이 비어있으면 카드사명으로 자동 설정
- 자동 입력 후에도 사용자가 자유롭게 수정 가능
- "직접 입력" 선택 시 필드 비우고 수동 입력

#### 4. 수정 모드 (isEditing)

- 기존 결제수단 수정 시에는 카드사 선택 UI를 표시하지 않음
- 결제일/마감일만 직접 수정 가능 (기존 동작 유지)

# 주간/월간 예산 연동 버그 + 일할 계산
> 날짜: 2026-03-19 | 회차: 5 | 상태: 기획 (다음 세션 진행 예정)

## 보고된 문제

### 1. 주간 지출이 월간 뷰에 반영 안 됨
- 주간 예산: 17,500원/주 설정
- 3주차: 지출 반영됨 ✓
- 월간 뷰: 800,000원 예산 / 0원 사용 ← **지출이 0원으로 표시됨**
- 원인 추정: 월간 뷰에서 주간 예산의 지출을 합산하는 로직 누락

### 2. 월 경계 주간 일할 계산 없음
- 주간 예산 200,000원이 하나의 주(7일)에 대한 예산
- 해당 주가 월 경계에 걸리면 **일수 비율로 각 월에 분배**
- 예: 2월 마지막주(월~수 3일) + 3월 첫주(목~일 4일)
  - 2월: 200,000 × 3/7 = 85,714원 / 2월에 속하는 날의 지출만 집계
  - 3월: 200,000 × 4/7 = 114,286원 / 3월에 속하는 날의 지출만 집계
- 현재: 이 분배 로직이 없음

## 조사 필요 사항

### BE: BudgetService.getBudgetSummary()
- 월간 뷰에서 주간 예산의 지출을 어떻게 합산하는지
- `budgetPeriod == WEEKLY`인 예산의 월간 지출 집계 로직
- 주간 예산 → 월간 환산 (weeklyAmount × 해당월주수)

### BE: WeeklyBudgetService
- 주별 예산 스냅샷 생성 로직
- 월 경계 주의 날짜 범위 계산
- 일할 계산 적용 여부

### FE: budget_list_page.dart
- 월간/주간 뷰 전환 시 데이터 표시 로직
- 주간 예산의 월간 요약 표시 방법

## 해결 방향

### 1. 주간 지출 → 월간 합산
- 월간 뷰에서 `budgetPeriod == WEEKLY` 예산 표시 시:
  - 예산액: weeklyAmount × 해당 월의 주 수 (또는 일할 계산)
  - 지출액: 해당 월 전체 기간의 카테고리별 지출 합산
- 주간/월간 구분 없이 **동일 카테고리의 지출은 항상 합산**

### 2. 일할 계산 로직 (핵심)

**기준**: 주간 예산 = 해당 주 7일에 대한 총 예산. 월 경계 시 일수 비율로 분배.

```
주간 예산: 200,000원/주

예시: 2026년 2~3월 경계
──────────────────────────────────
2월 마지막주 (2/24 월 ~ 3/2 일)
├── 2월에 속하는 날: 2/24~2/28 = 5일
│   → 2월 예산: 200,000 × 5/7 = 142,857원
│   → 2월 지출: 2/24~2/28 거래만 집계
├── 3월에 속하는 날: 3/1~3/2 = 2일
│   → 3월 예산: 200,000 × 2/7 = 57,143원
│   → 3월 지출: 3/1~3/2 거래만 집계
──────────────────────────────────
3월 2주차 (3/3 월 ~ 3/9 일) → 전부 3월
├── 예산: 200,000원 (전액)
├── 지출: 3/3~3/9 거래 집계
──────────────────────────────────
... 중간 주는 전부 3월 ...
──────────────────────────────────
3월 마지막주 (3/31 월 ~ 4/6 일)
├── 3월에 속하는 날: 3/31 = 1일
│   → 3월 예산: 200,000 × 1/7 = 28,571원
│   → 3월 지출: 3/31 거래만 집계
├── 4월에 속하는 날: 4/1~4/6 = 6일
│   → 4월 예산: 200,000 × 6/7 = 171,429원
──────────────────────────────────

3월 총 예산 = 57,143 + 200,000 × 4 + 28,571 = 885,714원
3월 총 지출 = 각 주의 3월 날짜에 해당하는 거래 합산
```

### 3. 주간 뷰에서의 표시 (주 단위)
```
3월 1주차 (3/1~3/2, 2일)
├── 예산: ₩57,143 (200,000 × 2/7)
├── 지출: ₩35,000
└── 잔여: ₩22,143

3월 2주차 (3/3~3/9, 7일)
├── 예산: ₩200,000
├── 지출: ₩180,500
└── 잔여: ₩19,500
```

### 4. 월간 뷰에서의 표시 (월 합산)
```
식비 예산 (주간 200,000원/주)
├── 3월 예산: ₩885,714 (일할 합산)
├── 3월 지출: ₩723,400
├── 잔여: ₩162,314
└── 사용률: 81.7%
```

### 5. 지출 집계 규칙
- **지출은 항상 거래 날짜(transactionDate) 기준**
- 3/1에 사용한 금액 → 3월 1주차 지출에만 포함
- 2/28에 사용한 금액 → 2월 마지막주차 지출에만 포함
- 월간 뷰 지출 = 해당 월 1일~말일 거래 합산 (주 구분 없이)

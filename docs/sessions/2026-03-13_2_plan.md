> 날짜: 2026-03-13 | 회차: 2 | 상태: 기획/검증완료

## 요청 내용
필드 테스트에서 발견된 실사용 수준의 심각한 문제들을 전문 감사팀(FE 디테일, BE API 안전성, UX 플로우 시뮬레이션)을 통해 전수 조사 후 수정.
- 저장 시 중복 데이터 생성 → FE+BE 양쪽 검증
- 수정 화면에서 삭제 불가
- 카테고리/포켓/결제수단 선택 시 없으면 인라인 추가 가능해야 함

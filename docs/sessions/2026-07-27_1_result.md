## 3. 구현 중 확정된 설계 (기획서와 달라진 점)

1. **navigation_state 구조적 수정 형태** — 정산은 별도 라우트가 아니라 거래 탭 뷰 모드이므로
   `reconciliation_route.dart` 대신 `ReconciliationView(year:, month:)` **required 파라미터**로
   컴파일 타임 강제. 월 소유권은 MonthCubit → `TransactionLoaded.year/month` 단일 경로 유지.
2. **미기록 목록 로딩** — 화면에 로드된 페이지를 재사용하지 않고 정산 뷰가
   `reconciled=false` 로 직접 조회(거래 200/페이지, 이체 월 전체). 200건 초과 시 표시 건수를
   문구로 명시(무언의 truncation 금지).
3. **P3 "이 달 정산 완료"** — 정산 뷰 상단 배너로만 구현. 리스트 모드 월 헤더 노출은 제외
   (월 합계 바 레이아웃 변경을 피함).
4. **배지 N+1 제거** — `ReconciliationRef` 가 스냅샷 `seq`/`reconciledAt` 을 읽으므로
   `JOIN FETCH i.reconciliation` 필수(커밋 7093a23).
5. **제외 범위** — P4(월말 인앱 알림), P6(홈 "미정산 N건" 위젯)은 별도 회차.

# StatisticsBloc 패턴 확장 — StatisticsFilter value object
> 날짜: 2026-04-20 | 회차: 4 | 상태: 완료

## 요청 내용
PR #103 에서 TransactionBloc 에 `currentFilter` getter + `TransactionFilter` VO 도입함.
같은 패턴을 StatisticsBloc 에 확장 (재발 방지 일관성 확보).

## 영향 범위
| 파일 | 변경 |

| `frontend/test/features/statistics/domain/entities/statistics_filter_test.dart` | 신규 — 6 테스트 |

## StatisticsFilter 필드 (5개)
- `categoryType` (EXPENSE/INCOME)
- `visibilityFilter` (ALL/SHARED/PRIVATE)
- `dateFrom` (nullable ISO)
- `dateTo` (nullable ISO)
- `dateRangeLabel` (nullable UI 라벨)

## 설계 근거
기존 `StatisticsState` 는 이미 필터를 state 에 저장 → 월 변경 시 drop 은 없었지만:
1. TransactionBloc 과 다른 API (drop 가능성 미래에 생길 수 있음)
2. 외부 consumer (MonthSyncHandler 등) 가 필드 개별 접근하면 누락 위험
3. PR-4 (LoadRecordsEvent<T>) 도입 시 통일된 인터페이스 필요

→ 지금부터 **currentFilter getter** 로 단일 접근점 강제.

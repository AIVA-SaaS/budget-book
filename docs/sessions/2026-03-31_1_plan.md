#### 0-3 한글 폰트 수정 상세

**현재 문제**:
- `google_fonts: ^6.2.1` 의존성이 pubspec.yaml에 있지만 코드에서 **전혀 사용하지 않음**
- 커스텀 폰트 번들 없음 (Material Icons만 있음)
- Flutter Web은 CanvasKit 렌더러 사용 시 시스템 폰트를 직접 로드하지 못함
- 한글 폰트가 네트워크에서 on-demand 로딩되면서 **tofu 현상** 발생

**수정 방안**:
1. `google_fonts` 의존성 제거 (미사용)
2. Noto Sans KR (또는 Pretendard) `.ttf` 파일을 `frontend/assets/fonts/`에 번들
3. `pubspec.yaml` fonts 섹션에 등록
4. `AppTheme`에서 `fontFamily: 'NotoSansKR'` 지정
5. 번들 폰트로 즉시 렌더링 → tofu 제거

**성능 설계**:
- Noto Sans KR Regular/Bold/Medium 3개 weight만 번들 (약 3~5MB)
- Variable font 사용 시 단일 파일 (~2MB)로 축소 가능
- 웹 빌드 시 `--dart-define`으로 불필요 weight 제외

## 7. 성능 설계

### 데이터 접근 패턴
- ReportService: 월별 리포트에서 동일 데이터 2~3회 중복 조회 → 1회로 통합
- getActiveCouple(): 요청 당 최대 83회 → RequestScope 1회로 축소
- 스케줄러: 100건 반복거래 시 단일 트랜잭션 → 개별 격리로 부분 실패 허용

### 예상 규모
- 현재: 소규모 (2명 사용), 향후 서비스화 시 확장 고려
- 폰트 번들: ~3-5MB 추가 (초기 로드 시간 vs tofu 방지 trade-off)

### 리소스 제약
- NAS: 메모리/CPU 충분 (Docker 기반)
- Rate Limiting: in-memory ConcurrentHashMap (현재 단일 인스턴스)

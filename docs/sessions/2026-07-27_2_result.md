## 2. 원인이 무엇이었나 (측정 기록)

- **잔액 수정이 정산에 보임** — 집계기가 금액만 빼고 `itemCount = entries.size` 로 건수는
  그대로였다. 라이브 ADJUSTMENT 13건이 미기록을 채워 "이 달 정산 완료" 도달 불가.
- **날짜 미표시** — 타일에 날짜가 없고(리스트 모드는 페이지가 날짜 헤더를 그린다) 정산 뷰는
  평면 리스트였다.
- **[전체 선택]/[정산 취소] 발견 실패** — 기능은 있었다. `ExpansionTile.trailing` 을
  `⋮` 로 덮어써서 **펼침 chevron 이 사라진 것**이 원인.
- **정산 아이콘 빈칸** — 서버 폰트에는 아이콘이 **있었다**(cmap 확인). `/assets/fonts/
  MaterialIcons-Regular.otf` 가 `immutable, max-age=1y` 인데 Flutter web 은 트리셰이킹 폰트를
  **해시 없는 고정 URL** 로 낸다 → 재방문 클라이언트가 구 서브셋 사용. PR #251(계산기
  아이콘)과 같은 전제 오류의 2회차.
- **유형 변경 불가** — FE 는 `"(유형 수정 불가)"` 라벨 고정, BE `UpdateTransactionRequest` 에
  `type` 필드 부재. 이체는 테이블이 달라 update 로는 원천 불가.

## 3. 사용자 라이브 검증 (이게 끝나야 "완료")

> **선행: 하드 리프레시 1회.** 웹 `Ctrl+Shift+R`, 모바일은 사이트 데이터 삭제.
> 이미 1년짜리로 캐시된 폰트는 헤더를 고쳐도 만료 전 재검증하지 않는다. 이번 한 번만 필요하다.

**A. 아이콘**

- A1 거래 탭 뷰 토글에 3번째 아이콘(✅ 체크 서류)이 보인다
- A2 정산 후 거래/이체 타일의 정산 배지 아이콘이 보인다

**B. 정산 뷰**

- B1 미기록 목록이 `7월 26일 (일)` 날짜 그룹으로 묶여 보인다 (리스트 모드와 같은 표기)
- B2 목록 맨 위 [전체 선택] 체크박스 → 전체 선택/해제, 우측에 "N건 선택"
- B3 날짜 헤더의 체크박스 → 그 날짜 항목만 선택
- B4 스냅샷 우측에 펼침 화살표(∨)가 보이고, 펼치면
  `[항목 전체 선택] [라벨 수정] [선택 N건 정산 취소] [전체 정산 취소]`
- B5 항목 2건 체크 → [선택 2건 정산 취소] → 확인 → **그 2건만** 미기록 복귀
- B6 [전체 정산 취소] → 스냅샷 사라지고 항목 전부 미기록 복귀 (거래 자체는 보존)

**C. 잔액 수정 제외**

- C1 잔액 수정 거래가 미기록 목록·건수·소계 어디에도 없다
- C2 잔액 수정만 남은 달 → "이 달 정산 완료" 배너
- C3 달력에서 잔액 수정이 있는 날도 나머지가 정산되면 완료 점 표시

**D. 거래 유형 변경**

- D1 거래 수정 화면 상단에 `유형 [지출|수입|이체]` 세그먼트
- D2 지출 → 수입 전환 시 카테고리가 비워지고 안내가 뜬다 → 카테고리 재선택 후 저장 성공
- D3 카테고리를 안 고치고 저장하면 서버가 막는다(에러 메시지 노출)
- D4 [이체] 선택 → 이체 폼(출금/입금 결제수단) → 저장 → **거래가 사라지고 이체가 생긴다**,
  월 합계에 이중 계상 없음
- D5 잔액 수정 거래를 열면 "잔액 수정 (유형 변경 불가)" 표기
- D6 정산에 기록된 거래의 유형/이체 변경 시도 → "정산에서 제외한 뒤 시도" 안내
- D7 카드 결제에 연결된 거래 / 지출 계획에 연결된 거래 → 각각 안내 메시지로 차단

**E. 회귀 없음**

- E1 리스트 모드 날짜 헤더·누적 지출·자산 잔액 숫자 불변
- E2 월 합계 바 수입/지출/이체 불변
- E3 달력 3줄 레이아웃 유지
- E4 이체 등록(일반/카드 결제) 정상 — 카드 결제 판정이 변환과 같은 컴포넌트로 바뀌었다
- E5 필터·월 이동·무한스크롤 정상

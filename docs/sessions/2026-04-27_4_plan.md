- **데이터 접근**: 변경 없음. sentinel 은 클라이언트 상수, BE 호출 0.
- **예상 규모**: sheet build 시 핀 카드 1개 추가. adjustmentOnly 모드 시 오히려 list 항목 적음.
- **리소스 제약**: 무관.
- **설계 결정**:
  - sentinel 카테고리 = `__ADJUSTMENT__` 상수. 실제 카테고리 UUID 와 절대 충돌 안 함.
  - submit 단계에서 sentinel → type=ADJUSTMENT, categoryId=null 변환. BE 는 ADJUSTMENT 그대로 받음.
  - direction radio (증가/감소) 는 부호 입력 실수 차단. 음수 amount textinput 처리는 회피.

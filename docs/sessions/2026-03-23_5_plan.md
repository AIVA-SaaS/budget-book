# 홈 탭 개편 + 통계 고도화
> 날짜: 2026-03-23 | 회차: 5 | 상태: 기획

## 요청 내용
1. 통계: 전체/공유/개인 별 예산 표시 (main에 이미 구현됨)
2. 통계 > 결제수단별: 클릭 시 해당 결제수단 거래 내역 보기
3. 홈 탭: 예산 알림과 예산 사용 현황 중복 → 통합/개편
4. 홈 탭: 결제수단별 금액 요약 + 클릭 시 내역 보기

## 홈 탭 현재 구조
```
[공지 배너]
[예산 알림]              ← 80%/100% 초과 경고
[월 헤더 (◀ 3월 ▶)]
[빠른 메뉴]
[이번 달 요약]           ← 수입 / 지출 / 잔액
[나만 보임 요약]
[예산 사용 현황]         ← 중복: 알림과 비슷한 정보
[최근 거래]
```

## 개편 후 구조
```
[공지 배너]
[월 헤더 (◀ 3월 ▶)]
[빠른 메뉴]
[이번 달 요약]           ← 수입 / 지출 / 잔액 (유지)
[나만 보임 요약]         ← (유지)
[지출 요약 카드]         ← 신규: 총 사용 금액
  └─ 클릭 펼침:
     ├─ 예산별: 금액 & 사용금액 (프로그레스 바)
     └─ 카테고리별: 사용 금액 (많은 순)
[결제수단별 카드]        ← 신규
  └─ 결제수단별 사용 금액
     └─ 클릭 시: 해당 결제수단 거래 내역 페이지로 이동
[예산 알림]              ← 이동: 맨 위 → 여기로
[최근 거래]
```

## 작업 계획

### 1. 홈 탭 데이터 확장
- DashboardBloc에 카테고리별 지출, 결제수단별 지출 데이터 추가
- 기존 statistics API의 `sumByCategoryForCouple`, `sumByPaymentMethodForCouple` 활용
- 또는 별도 API 없이 기존 budget summary + 추가 쿼리

### 2. 홈 탭 레이아웃 변경
| 변경 | 파일 |
|------|------|
| BudgetAlertWidget 위치 이동 (맨 위 → 하단) | dashboard_page.dart |
| BudgetUsageCard → SpendingSummaryCard 교체 | dashboard_page.dart |
| PaymentMethodSummaryCard 추가 | dashboard_page.dart (new widget) |
| DashboardBloc에 카테고리/결제수단 데이터 | dashboard_bloc.dart, dashboard_state.dart |

### 5. 통계 > 결제수단별 상세
- 결제수단 항목 클릭 → 거래 목록 필터링
- 기존 거래 목록 페이지의 `paymentMethodId` 필터 활용
- 라우팅: `/transactions?paymentMethodId=uuid`

## 필요한 API 데이터
| 데이터 | API | 상태 |
|--------|-----|------|
| 예산 summary | GET /budgets/summary | 기존 |
| 카테고리별 지출 | statistics API | 기존 |
| 결제수단별 지출 | sumByPaymentMethodForCouple | BE 기존 쿼리, FE 미노출 |

## 성능 설계
- 홈 탭 로드 시 3→4개 병렬 API 호출 (budget summary, statistics, transactions, 결제수단별)
- 결제수단별 지출은 기존 statistics API에 포함 가능
- 추가 API 호출 최소화

# Phase 19: 카드 대금 결제 기능
> 날짜: 2026-04-14 | 회차: 3 | 상태: 기획

## 요청 내용
신용카드 대금 결제를 기록하는 전용 기능:
1. 카드 선택 → 전월 해당 카드 총 사용액 자동 표시
2. 아래에 전월 거래 내역 목록 (화살표로 펼치기)
3. 개별 거래 체크/언체크로 결제 항목 조절
4. 총 결제 금액 수동 조절 가능
5. 결제 실행 → 은행 계좌에서 출금 기록 (Transfer 생성)

## 영향 범위 (Scope Manifest)

### 공통 적용 여부 판단
- **금액 계산**: 기존 `getCardSettlementSummary`의 미결제 금액 활용 → 새 로직 불필요
- **Transfer 생성**: 기존 `TransferService.createTransfer` 재사용 → 새 API 불필요
- **거래 목록 조회**: 기존 `listTransactions(paymentMethodId=xxx)` + settlementDate 필터 필요

### 결제 실행 로직
1. 사용자가 "결제 실행" 탭
2. 확인 다이얼로그: "₩1,250,000을 [신한은행]에서 [삼성카드]로 결제하시겠습니까?"
3. 확인 → `POST /api/v1/transfers` 호출:
   - source: linkedBank (또는 선택한 출금 계좌)
   - destination: 선택한 카드
   - amount: 입력된 결제 금액
   - description: "삼성카드 4월 결제"
   - transferDate: 선택한 결제일
4. 성공 → PaymentMethodBloc 갱신 + 결제수단 페이지로 복귀

## 성능 설계
- **결제 대상 거래 조회**: 기존 인덱스 `(payment_method_id, settlement_date)` 활용, 추가 인덱스 불필요
- **거래 목록**: 한 카드의 한 달 거래 = 보통 20-50건 → 페이징 불필요
- **Transfer 생성**: 기존 API 재사용, 추가 부하 없음

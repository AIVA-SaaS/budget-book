## 원인 분석

### 문제 1: MonthNavigator 표시 불일치 (구조적 버그)
```dart
// 현재 각 페이지:
MonthNavigator(
  year: state.year,   // StatisticsBloc/BudgetBloc 등 자체 state
  month: state.month,
  onMonthChanged: (m) => context.read<MonthCubit>().changeMonth(...),
)
```

- `onMonthChanged` → MonthCubit 업데이트됨
- MonthSyncHandler가 해당 BLoC reload → BLoC.state.year/month 업데이트됨
- **UI는 state.year/month 표시** → 올바른 값이지만 **다른 페이지 이동 후 돌아올 때 문제**

시나리오:
- 홈에서 1월로 이동 → MonthCubit=1월, DashboardBloc=1월
- 통계 페이지로 이동 → MonthSyncHandler가 StatisticsBloc LoadAllStatistics(1월) dispatch
- 그러나 StatisticsPage 초기 로드 시 StatisticsBloc.state는 이미 4월 (페이지 첫 진입 시 `now.year/month`로 초기화됨)
- 만약 MonthSyncHandler가 업데이트되기 전에 StatisticsPage 빌드되면 → state.year=4 표시
- 또는 StatisticsBloc의 `state.year/month`가 이전 값 유지

**근본 원인**: 각 BLoC이 자체 year/month state 유지. MonthCubit은 별도. 두 state source가 sync는 되지만 **UI는 BLoC state를 표시**.

**해결**: MonthNavigator가 MonthCubit.state를 우선 사용. BLoC state는 내부 쿼리용.

### 문제 2: buildMonthBySettlementDate의 transferOut 포함 (설계 결함)
```kotlin
// PaymentMethodService.kt:282-285
val transferOutMap = transferRepository.sumAmountBySourceExcludingSettlement(
    couple.id, startDate, endDate
)...
pendingAmount = txnAmount + transferOut  // ← transferOut는 미결제와 무관
```

**미결제 금액의 정의**: 해당 월에 결제해야 할 카드 청구액
- 신용카드 청구 = 카드로 사용한 **거래** (Transaction)
- 카드는 source로 이체 불가능 (신용카드에서 돈 나가는 개념 자체가 없음)
- 따라서 `transferOut` (source=카드인 이체)은 미결제와 무관

`buildMonthByTransactionDate`는 "카드 사용량"이고, Transfer out도 카드 관련 flow라 표시할 수 있지만,
`buildMonthBySettlementDate`는 "결제할 청구액"이므로 Transaction만 집계해야 함.

**해결**: buildMonthBySettlementDate에서 transferOut 제거.

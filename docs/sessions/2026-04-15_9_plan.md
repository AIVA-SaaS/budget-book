### 🔴 3개 결함 발견

#### 결함 1: AccountBalanceCard — BlocBuilder 없음 (가장 치명적)
- **파일**: `core/widgets/account_balance_card.dart:15-25`
- **문제**: `final pmState = getIt<PaymentMethodBloc>().state;` 직접 호출
- **결과**: PaymentMethodBloc state 변경해도 **위젯 rebuild 안 됨**
- **영향**: 홈/예산 페이지의 자산 현황 카드가 월 이동 시 stale

#### 결함 2: MonthSyncHandler — LoadCurrentWeek 누락
- **파일**: `core/bloc/month_sync_handler.dart:97-99`
- **현재**: `LoadWeeklyOverview`만 dispatch
- **누락**: WeeklyBudgetPage의 `_onMonthChanged`는 `LoadCurrentWeek`도 호출
- **영향**: 주간 예산 페이지 외 다른 페이지에서 월 변경 시 LoadCurrentWeek 미실행 → 주간 요약 stale

#### 결함 3: MonthSyncHandler — LoadWeeklyReport 누락
- **파일**: `core/bloc/month_sync_handler.dart:101-103`
- **현재**: `LoadMonthlyReport`만 dispatch
- **누락**: ReportPage의 `_changeMonth`는 `LoadWeeklyReport(..., week: week)`도 호출
- **영향**: 리포트 페이지 외에서 월 변경 시 주간 리포트 stale

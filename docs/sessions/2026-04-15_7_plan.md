## 구조적 수정 계획

### 목표
모든 월 의존 페이지가 다음 규칙 따름:
- MonthNavigator onMonthChanged → `MonthCubit.changeMonth()`만 호출
- MonthNavigator year/month 값 → `context.watch<MonthCubit>().state.year/month`
- 개별 BLoC 이벤트 dispatch는 MonthSyncHandler가 자동 처리

### 작업 범위

### 주의: 각 페이지의 local state 제거 시 필드 참조도 제거
`_year`, `_month` local state를 쓰던 페이지들은 `context.watch<MonthCubit>()` 또는 BLoC state의 year/month로 대체.

### MonthSyncHandler 확장
```dart
void _syncAllMonthDependentBlocs(int year, int month) {
  _trySync<BudgetBloc>(() => LoadBudgets(year: year, month: month));
  _trySync<DashboardBloc>(() => LoadDashboard(year: year, month: month));
  _trySync<PaymentMethodBloc>(() => LoadCardSettlementSummary(year: year, month: month));
  // 신규 추가
  _trySync<TransactionBloc>(() => LoadTransactions(year: year, month: month));
  _trySync<TransferBloc>(() => LoadTransfers(year: year, month: month));
  _trySync<StatisticsBloc>(() => LoadAllStatistics(year: year, month: month));
  _trySync<SpendingPlanBloc>(() => LoadSpendingPlans(year: year, month: month));
  _trySync<WeeklyBudgetBloc>(() => LoadWeeklyBudgets(year: year, month: month));
  _trySync<ReportBloc>(() => LoadReport(year: year, month: month));
  _trySync<AiInsightBloc>(() => LoadInsights(year: year, month: month));
}
```

## 성능 설계
- MonthCubit changeMonth: 같은 월이면 emit 생략 (중복 reload 방지)
- MonthSyncHandler: 월 변경 1회당 등록된 BLoC 각각 1회 reload — 기존 수동 dispatch와 동일
- 필터 파라미터(paymentMethodId, categoryId)가 필요한 BLoC은 page-specific context에서 별도 처리

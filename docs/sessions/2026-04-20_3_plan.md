## 근본 원인 (탐색 에이전트 리포트)

**3개 유사 도메인 간 공통화 실패** — Transaction / Transfer / PocketTransfer:

1. **Entity 중복**: 13개 필드 중 6개가 제각각 선언 (id, coupleId, author, amount, dateField, createdAt). `updatedAt` 필드 Transaction/Transfer 에만 있고 PocketTransfer 에 없음.
2. **BLoC Event 파라미터 불균형**: `LoadTransactions` 12개 파라미터 vs `LoadTransfers` 2개. 필터 의미 같은데 서명 다름.
3. **State 구조 중복**: Initial→Loading→Loaded/Error 3개 BLoC 반복. Loaded 필드 제각각.
4. **Form 거대 단일 파일**: `transaction_form_page.dart` (1717줄) vs `transfer_form_page.dart` (447줄). 금액/날짜/메모 컨트롤러 6개 중복.
5. **Repository/DataSource**: `getTransactions()` 12 param vs `getTransfers()` 2 param. `queryParameters` 생성 + Dio 에러 처리 복제.
6. **DTO 금액/날짜 필드 타입 불일치**.
7. **UI 타일/카드 위젯 분산**: 같은 Dismissible 패턴 별도 파일.
8. **Formatter/Helper 호출 산발**: `CurrencyFormatter.format()` 8곳 + 직접 쉼표 처리 2곳.
9. **에러 메시지 한글/영문 혼재** (Repository vs DataSource 레벨).
10. **월 감지 `_currentYear/Month` 페이지 로컬 중복** — MonthCubit 있음에도 미사용 영역 있음.

## 구조적 수정 계획 (Base + Variant Overlay 패턴)

### 1. `RecordBase` 추상 entity
```dart
// core/domain/entities/record_base.dart
abstract class RecordBase extends Equatable {
  final String id;
  final String coupleId;
  final TransactionAuthor author;
  final int amount;
  final String dateField;          // ISO yyyy-MM-dd
  final DateTime createdAt;
  final DateTime? updatedAt;
  final String? description;
  final String? memo;

  const RecordBase({ required id, ... });
}

class Transaction extends RecordBase { /* category, paymentMethodId, ... */ }
class Transfer extends RecordBase { /* sourcePaymentMethod, destinationPaymentMethod */ }
class PocketTransfer extends RecordBase { /* fromPocket, toPocket */ }
```
- 6개 공통 필드 **상속 강제** → 누락 시 컴파일 에러
- `updatedAt` 자동 동기화 (PocketTransfer 누락 문제 해결)

### 2. `LoadRecordsEvent<T>` 공통 기본
```dart
abstract class LoadRecordsEvent<T> extends RecordEvent {

  final PeriodFilterArgs? filter;  // 공통 필터 VO

class LoadTransactions extends LoadRecordsEvent<Transaction> { ... }
class LoadTransfers extends LoadRecordsEvent<Transfer> { ... }
```

- 필터 field 추가 시 한 곳(`PeriodFilterArgs`) 만 수정 → 모든 Event 반영

### 3. `RecordLoaded<T>` 공통 state
```dart
abstract class RecordLoaded<T> extends RecordState {
  final List<T> items;
  final int year, month;
  final String? operationError, operationSuccess;

  int get totalAmount => items.fold(0, (s, x) => s + (x as dynamic).amount);
  Map<String, List<T>> get groupedByDate { ... }
}
class TransactionLoaded extends RecordLoaded<Transaction> { /* + 페이징, 집계 */ }
class TransferLoaded extends RecordLoaded<Transfer> { /* 기본만 */ }
```
- `totalAmount`, `groupedByDate` 중복 제거

### 4. `GenericRemoteDataSource<T>`

# Phase 20-F: 월 변경 중앙화 — MonthCubit 구조적 수정
> 날짜: 2026-04-15 | 회차: 6 | 상태: 승인

## 요청 내용
월 이동 시 카드 요약이 페이지마다 수동 reload 필요한 구조적 문제 해결.
Phase 20-E는 패치 수정으로 특정 3개 지점만 수정. 새 페이지/BLoC 추가 시 또 누락될 위험.

- **실행**: `recurrence_check.py . "navigation_state,amount_calculation"`
- **amount_calculation**: 🚫 STRUCTURAL_FIX_REQUIRED (6회째)
- **navigation_state**: 🚫 STRUCTURAL_FIX_REQUIRED (2회, 경고)
- **필수 조치**: 패치 불허, 구조적 수정 필수

## 구조적 수정 계획

### 현재 구조 (문제)
```
각 페이지가 자체 월 상태 관리:
- BudgetListPage: BudgetState.year/month → LoadBudgets 호출
- DashboardPage: DashboardState.year/month → LoadDashboard 호출
- TransactionListPage: TransactionState.year/month → LoadTransactions 호출
- StatisticsPage: StatisticsState.year/month → LoadStatistics 호출
- PaymentMethodPage: _year/_month → LoadCardSettlementSummary 호출

→ 월 변경 시 각 페이지가 자기 BLoC만 reload.
→ 카드 요약은 PaymentMethodBloc에 있는데, 다른 페이지들이 이걸 안 건드림.
→ 매번 수동 추가 필요 = 누락 발생.
```

### 새 구조 (해결)
```
MonthCubit (전역 단일 소스):
  - state: (year, month)
  - 모든 월 네비게이터가 이것만 업데이트

MonthSyncHandler (중앙 리로드 핸들러):
  - MonthCubit 구독
  - 월 변경 시 등록된 모든 월 의존 BLoC reload 실행
  - 새 BLoC 추가 시 여기에만 등록

월 의존 BLoC들:
  - BudgetBloc: monthCubit.year/month 바뀌면 → LoadBudgets
  - DashboardBloc: → LoadDashboard  
  - PaymentMethodBloc: → LoadCardSettlementSummary
  - (향후 추가 시 MonthSyncHandler에만 등록)
```

### 영향 범위
| 파일 | 변경 |
|------|------|
| `frontend/lib/core/bloc/month_cubit.dart` (신규) | 전역 월 상태 관리 |
| `frontend/lib/core/bloc/month_sync_handler.dart` (신규) | 월 변경 broadcast 핸들러 |
| `frontend/lib/core/di/injection.dart` | MonthCubit + handler 등록 |
| `frontend/lib/main.dart` | MultiBlocProvider에 MonthCubit 추가 |
| `frontend/lib/features/budget/presentation/pages/budget_list_page.dart` | MonthNavigator onMonthChanged → MonthCubit.change |
| `frontend/lib/features/home/presentation/pages/dashboard_page.dart` | _MonthHeader 버튼 → MonthCubit.change |

**중요**: 기존 BLoC state의 year/month는 유지. MonthCubit은 UI 탐색 상태 전용.
각 BLoC은 자체 year/month를 내부적으로 유지하고, MonthSyncHandler가 월 바뀌면 관련 Load 이벤트 dispatch.

## 성능 설계
- MonthCubit: 단순 Cubit, 상태 1개 (year, month), 메모리 미미
- MonthSyncHandler: 월 변경 시 한 번만 reload 이벤트 dispatch (중복 없음)
- 기존 BLoC 동작 불변, 추가 오버헤드 없음

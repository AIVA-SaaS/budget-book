> 날짜: 2026-04-14 | 회차: 2 | 상태: 기획

## 요청 내용
사용자 피드백:
1. 지출/수입/공유/개인 필터 → **별도 세그먼트가 아니라 필터 바텀시트 안에 포함**
2. 필터 아이콘, 날짜, 활성 칩이 각 줄 분리 → **UI 깨짐 정리**
3. 카드 결제 예정 위젯은 **거래 목록이 아닌 결제수단 관리 페이지(예산 탭)에 이미 존재** → 거래 목록에 추가한 것 제거 (롤백 완료)
4. 카드별 금액(전월/미결제/이번달)이 **0원으로 표시** → 데이터 로직 수정 필요

## 분석 결과

### 이슈 1-2: 필터 UI/UX 문제 (거래 목록)

**현재 구조** (롤백 후 상태):
```
Row 1: 🎛️ tune(바텀시트) + 📅 date(별도 시트)  ← 아이콘 2개
Row 2: [카테고리X] [기간X] [카드X]              ← 활성 칩 (Wrap, 줄바꿈 가능)
```

**문제점**:
- 거래 유형(지출/수입)과 공개 범위(공유/개인) 필터가 **아예 없음**
- 날짜 필터와 기타 필터가 **서로 다른 UI**(별도 아이콘 vs 바텀시트)
- 활성 칩이 Wrap으로 자동 줄바꿈 → 필터 3개+ 시 거래 목록 영역 -44dp

**해결**: 모든 필터를 하나의 바텀시트에 통합 + 칩 한 줄 제한

### 이슈 3: 카드 결제 예정 위치 (해결됨)
- 결제수단 관리 페이지(`payment_method_page.dart:292-331`)에 **이미 구현** → `_buildCardSettlementSummary()`
- 전월 결제 / 이번달 결제 2칸으로 표시 중
- 거래 목록에 추가한 CardPendingSummary는 **롤백 완료** (커밋 `8f74852`)

### 이슈 4: 카드 결제 현황 0원 — 근본 원인 분석

**사용자가 원하는 계산**:
| 항목 | 계산 방식 |
|------|---------|
| 전월 | 전월 해당 결제수단 총 지출액 (`transactionDate` 기준) |
| 미결제 | 전월 카드 사용 중 이번달에 결제될 금액 (`settlementDate` 기준) |
| 이번달 | 이번달 해당 결제수단 총 지출액 (`transactionDate` 기준) |

**현재 BE 구현** (`PaymentMethodService.getCardSettlementSummary`, 라인 231-275):
```kotlin
fun buildMonth(yearMonth: YearMonth): CardSettlementMonth {
    // settlementDate 범위로 조회 ← 문제!
    val results = transactionRepository.sumByPaymentMethodAndSettlementDateRange(
        paymentMethodId = card.id,
        startDate = yearMonth.atDay(1),     // 해당 월 1일
        endDate = yearMonth.atEndOfMonth(), // 해당 월 말일
        userId = userId
    )
}
```

**문제**:
1. **전월/이번달 모두 `settlementDate` 기준 조회** → 사용자가 원하는 "해당 월 총 지출액"은 `transactionDate` 기준이어야 함
2. `settlementDate`가 null인 거래(closingDay/settlementDay 미설정)는 집계에서 **완전 누락**
3. **미결제 개념 미구현** — 현재는 전월/이번달 2칸만 있고, "미결제" 항목이 없음

**0원 표시 원인**: closingDay/settlementDay 미설정 → settlementDate = null → 쿼리 결과 0

## 발견된 추가 이슈 (follow-up 후보)
1. **Health check 60s timeout** — Spring Boot 가 가끔 70~80초 시작. `deploy-nas.yml` 의 health check 10회×6s 를 20회×6s 또는 timeout 그대로 + retry 횟수 늘리는 방향. 본 세션 미적용.
2. **GitHub Actions cache 400 에러** — 일시적 cache service 장애. cache hit 정상 시 gradle bootJar 1m39s → ~30s 단축 예상. 외부 의존, 자체 해결됨.
3. **C-2.7 applyToFuture=true + TEMPLATE 시작월 < viewing 분리** — V60 으로 multi-segment TEMPLATE 허용되었으니 이제 처리 가능. 별도 follow-up 으로 split 로직에 추가 분기 추가 가능 (현재는 전체 TEMPLATE 적용).

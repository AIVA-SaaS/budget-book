## 3. Phase 24 PR 맵 (Y 시리즈)

### PR-Y1 (HIGH) — Visibility chip 통합
- `FilterType.visibility` 를 `transaction_list_page.dart:433` enabledFilters 에서 제거
- 글로벌 chip 라벨 통일: `전체 / 공유 / 개인` (main_shell:234 + unified_filter_bar:73 + visibility_cubit 문서)

### PR-Y2 (HIGH, L) — 분석 예산 섹션 완전 복원
- `BudgetSummaryCard` 하단에 **개별 예산 리스트** 이식 (`_buildBudgetTile` + 3-segment progress bar from `budget_list_page:604-876`)
- `_onPeriodChanged` 를 실제 동작하도록 wiring:
  - 월별: 기존 BudgetBloc.summary
  - 주별: `WeeklyBudgetBloc.LoadWeeklyOverview`
  - 연별: 아직 BE 미지원 → 비활성 + tooltip
- "전월 복사" / "예산 추가" / "주간 예산 보기" action 헤더 또는 inline 버튼
- 예산 타일 tap → `showBudgetTransactionsSheet` 복원
- Dismissible 복원

### PR-Y3 (HIGH, L) — 분석 카테고리 섹션 확장
- 기존 `CategoryBreakdownTab` 위젯 재사용 (또는 포팅)
- **그룹 헤더 + 드릴다운** (하위 카테고리)
- **지출 / 수입 SegmentedButton**
- 파이/행 `onTap` → `/transactions?categoryId=…&categoryName=…`
- 카테고리 필터 chip 복원

### PR-Y4 (HIGH, M) — 분석 탭 상단 액션 + 전년 비교 + 기간 범위
- AppBar/헤더에 `기간별 상세` 버튼 → `/period-summary`
- **전년 비교 섹션** 복원 (`YearComparisonTab` 포팅)
- **기간 범위 picker** 복원 (`statistics_page:83-113`)

### PR-Y5 (MED, M) — 자산 탭 레이아웃 수정
- `asset_management_page.dart:1063-1078`: `balance == null` 시 `잔액: 0원` fallback
- 인라인 `IconButton(Icons.tune)` (line 948-953) **제거**, popup 에 "잔액 수정" 항목 **추가** (비-카드만) — U2 해결
- 상단에 **MonthNavigator** + 3열 카드 결제 summary (`전월 / 미결제 / 이번달`) 카드 이식 (`payment_method_page:351-440`)

### PR-Y6 (MED, S) — 거래 탭 toggle 위치 수정
- `_buildViewToggle` 을 `UnifiedFilterBar` 와 **같은 행**에 배치 (필터 바 trailing slot 또는 Row 래핑)

### PR-Y7 (MED, M) — 더보기 탭 확장
- AI 인사이트 / 지출 계획 / 위시리스트 / 공지사항 진입 포인트 (`AnnouncementBanner`, `/spending-plans`, `/ai-insights` 등)
- 카드 자체 내장 대신 "바로가기" 리스트 형태

### PR-Y8 (LOW, S) — 추가 복원
- 결제수단별 도넛 `onTap` → 필터링된 `/transactions`
- MonthlyTrendCard 에 balance line 옵션
- QuickActions 복원 (거래 탭 상단 또는 FAB sub-buttons)

### PR-Y9 (CLEANUP, S) — Orphan 정리 결정
Phase 24 후 최종 결정:

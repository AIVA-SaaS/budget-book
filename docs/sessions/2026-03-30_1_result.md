## 해결된 문제

1. **완료 시 description 수정 불가** → TextField 추가, 사용자가 실제 결제 내용으로 수정 가능
2. **거래 미등록** → createTransaction 체크박스 제거, 항상 completeWithTransaction 호출
3. **완료 후 거래 목록 미갱신** → TransactionBloc.LoadTransactions 자동 호출 (거래일 기준 월)
4. **상태 이력 추적 없음** → spending_plan_status_history 테이블 + 모든 상태 변경 시 자동 기록
5. **완료 항목 날짜 미표시** → 카드에 "계획 YYYY-MM-DD → 완료 YYYY-MM-DD" 표시
6. **BLoC 원자성 위반** → LoadWishlist + LoadSpendingPlans 이중 디스패치 제거

## 향후 활용 (통계/분석 기반)
- `spending_plan_status_history` 테이블로 다음 통계 산출 가능:
  - 계획 달성율 (COMPLETED / (COMPLETED + SKIPPED + OVERDUE))
  - 계획 대비 실제 금액 차이 평균
  - 상태 전환 소요 시간 (PLANNED→COMPLETED 걸린 일수)
  - 사용자별 계획 이행 패턴

## 알려진 제한사항 (기존 이슈, 이번 범위 밖)
- FE `authorName` vs BE `authorNickname` 필드명 불일치 (작성자명 항상 빈 문자열)

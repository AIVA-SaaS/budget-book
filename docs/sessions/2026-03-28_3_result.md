## 요약

Phase 11 코드가 NAS에 자동 배포되어 라이브 운영 중.

## 배포 구조

```
[Client] → https://aiva-bb.duckdns.org
              ↓ nginx :443 (SSL/Let's Encrypt)
              ├── /api/*, /oauth2/*, /ws → Docker bb_app :8081 (Spring Boot)
              └── /* (SPA) → /var/services/web_bb/ (Flutter Web 정적 파일)

NAS Docker:
  ├── bb_app (bb-backend, :8081→8080) — Spring Boot API
  ├── db_postgres_bb (postgres:16, :5433→5432) — PostgreSQL
  └── redis_bb (redis:7, :6380→6379) — Redis
```

## CI/CD 파이프라인

```
develop push → CI (Backend CI + Frontend CI) 자동 실행
main push → Deploy to NAS (deploy-nas.yml) 자동 실행
  ├── deploy-backend: SSH → git pull → docker build → docker run → health check
  ├── deploy-frontend: Flutter build → SCP → /var/services/web_bb
  └── verify: curl health + site load
```

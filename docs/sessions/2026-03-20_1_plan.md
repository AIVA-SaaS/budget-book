# 거래 입력 UX 고도화 (자동완성 + 키보드 네비게이션)
> 날짜: 2026-03-20 | 회차: 1 | 상태: 기획 (추후 진행)

## 요청 내용

### 1. 내용(description) 자동완성
거래 내용 입력 시 기존에 입력한 내용들이 아래 드롭다운으로 제안되어 선택 가능.

**동작**:
- 사용자가 "점"을 입력 → "점심 식사", "점심 커피" 등 기존 내역 제안
- 제안 항목 클릭 시 자동 입력
- 해당 거래의 카테고리/결제수단도 함께 자동 설정 (옵션)

**구현 방향**:
- BE: `GET /api/v1/transactions/suggestions?q=점` — 기존 description 검색
- FE: `Autocomplete<String>` 위젯 또는 커스텀 드롭다운

### 2. 키보드 네비게이션 (웹 접근성)
모든 입력 항목을 Tab/방향키/Enter로 탐색 가능.

**현재 문제**:
- Tab으로 금액 → 내용까지는 이동되지만 카테고리에서 멈춤
- 카테고리/결제수단/포켓은 바텀시트로 열리는데 키보드로 제어 불가

**구현 방향**:
- 카테고리/결제수단/포켓 필드에 `FocusNode` 설정
- Enter/Space 키로 선택 시트 열기
- 시트 내부에서 방향키로 항목 이동, Enter로 선택
- Tab으로 다음 필드로 자연스럽게 이동

**Flutter Web 키보드 접근성 패턴**:
```dart
Focus(
  onKeyEvent: (node, event) {
    if (event is KeyDownEvent && event.logicalKey == LogicalKeyboardKey.enter) {
      _openSelectorSheet();
      return KeyEventResult.handled;
    }
    return KeyEventResult.ignored;
  },
  child: ItemSelectorField(...),
)
```

## 기술적 고려사항
- 자동완성: `DISTINCT description` 쿼리 + LIKE 검색, 인덱스 추가
- 키보드 네비게이션: Flutter Web의 `FocusTraversalGroup` 활용
- 접근성: `Semantics` 위젯으로 스크린 리더 지원

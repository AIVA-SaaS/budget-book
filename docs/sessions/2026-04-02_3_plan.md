# 폼 UI 일관성 전수 수정
> 날짜: 2026-04-02 | 회차: 3 | 상태: 기획

## 전수 조사 결과

10개 폼/다이얼로그에서 **6가지 불일치** 발견:

### 1. 삭제 버튼 누락 (edit 모드)
| 폼 | 삭제 버튼 | 수정 필요 |
|----|----------|----------|
| 거래 수정 | ✅ | - |
| 이체 수정 | ✅ | - |
| 지출계획 수정 | ✅ | - |
| 반복거래 수정 | ✅ | - |
| **예산 수정** | ❌ 없음 | ✅ 추가 |
| **보험 수정** | ❌ 없음 | ✅ 추가 |

### 2. 버튼 텍스트 불일치
| 현재 | 폼 | 통일안 |
|------|-----|--------|
| '저장' | 거래, 이체, 지출계획, 보험 | **'저장'** |
| '추가'/'수정' | 예산, 반복거래, 카테고리, 결제수단 | → **'저장'** |
| '등록' | 피드백 | → **'저장'** |

### 3. 필드 순서 불일치
**표준 순서** (거래 폼 기준):
```
날짜 → 금액 → 이름/설명 → 선택자(카테고리/결제수단) → 선택항목(메모 등) → 저장
```

| 폼 | 현재 순서 | 수정 필요 |
|----|----------|----------|
| 거래 | 날짜→금액→설명→카테고리→결제수단→메모 | ✅ 기준 |
| 이체 (독립) | 날짜→금액→출금→입금→설명→메모 | ✅ 이미 수정됨 |
| 이체 (내장) | 날짜→금액→출금→입금→내용→메모 | ✅ 이미 일치 |
| **보험** | 이름→보험사→금액→결제일... | ✅ 수정: 날짜→금액→이름→... |
| **반복거래** | 유형→금액→설명→주기→카테고리→결제수단 | ✅ 수정: 주기→금액→설명→카테고리→결제수단→메모 |
| 예산 | 기간→카테고리→금액 | ⚪ 특수 폼, 유지 |
| 지출계획 | 모드별 다름 | ⚪ 복합 폼, 유지 |
| 카테고리/결제수단 | 시트 형태 | ⚪ 유지 (미니 폼) |
| 피드백 | 카테고리→제목→내용 | ⚪ 유지 |

### 4. 완료 다이얼로그 검증 방식
| 현재 | 변경 |
|------|------|
| SnackBar로 에러 표시 | → Form.validate() + inline error |

### 5. 성공 후 피드백 없음
대부분 폼이 저장 성공 시 **조용히 pop**만 함. 사용자에게 성공 피드백이 없음.
→ 모든 폼에 성공 스낵바 추가: "저장되었습니다" / "수정되었습니다" / "삭제되었습니다"

### 6. 삭제 확인 다이얼로그 불일치
있는 곳은 AlertDialog, 없는 곳은 아예 삭제 불가.

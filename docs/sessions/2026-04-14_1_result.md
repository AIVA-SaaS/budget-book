## 해결된 이슈

### 이슈 1: AI 인사이트 네비게이션
- **Before**: 모든 인사이트 → 예산 관리 페이지 (shell.goBranch(2) 하드코딩)
- **After**: SPENDING_CHANGE/TIP → 해당 카테고리 거래 내역, BUDGET_WARNING/ADJUST → 예산, PATTERN/POSITIVE → 네비게이션 없음

### 이슈 2: 필터 금액 불일치
- **Before**: PeriodSummary 필터 UI는 있지만 API에 미전달 → 합계는 전체 데이터 기준
- **After**: categoryId/paymentMethodId가 API까지 전달, BE에서 Specifications 기반 필터 쿼리 실행

### 이슈 3: 필터/조회 미작동
- **Before**: dateFrom/dateTo가 BLoC→Repo→DataSource 체인에서 누락, 클라이언트 사이드 필터링으로 대체 → 페이징과 조합 시 데이터 손실
- **After**: 서버 사이드 필터링으로 전환, 전체 체인에서 dateFrom/dateTo 전달

### 이슈 4: 카드 금액 불일치
- **Before**: getMonthlySummary는 Transfer 포함, getPeriodSummary는 미포함 → 동일 기간 다른 금액
- **After**: 두 API 모두 Transfer 포함으로 통일, 필터 사용 시 Transfer 제외 (Transfer는 카테고리 없음)

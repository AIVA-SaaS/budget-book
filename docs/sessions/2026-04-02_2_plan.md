## 구현 계획

### E-1: AI 거래 자동 분류 (Claude API)

**개요**: 거래 설명(description)을 기반으로 카테고리를 자동 추천

**설계**:
```
[사용자] 거래 입력 시 설명 입력
  → [FE] 설명 입력 완료 (debounce 1초)
  → [BE] POST /api/v1/ai/classify
      body: { description, amount, type, existingCategories[] }
  → [Claude API] 프롬프트로 분류 요청
  → [BE] 추천 카테고리 2~3개 반환
  → [FE] 카테고리 필드에 추천 칩 표시 (사용자 선택)
```

**BE 구현**:
- `backend/build.gradle.kts` — Anthropic SDK 추가 (`com.anthropic:anthropic-java`)
- `com.budgetbook.ai/` 패키지 신규
  - `AiClassificationService.kt` — Claude API 호출, 프롬프트 관리
  - `AiController.kt` — `POST /api/v1/ai/classify`
  - `AiDtos.kt` — ClassifyRequest, ClassifyResponse
- API key: 환경변수 `ANTHROPIC_API_KEY`
- Rate limit: 10회/분/사용자 (기존 RateLimiter 활용)

**FE 구현**:
- `transaction_form_page.dart` — 설명 입력 시 자동 분류 요청, 추천 칩 표시
- `ai_remote_datasource.dart` — API 호출

**프롬프트 설계**:
```
사용자의 기존 카테고리 목록: [식비, 교통비, 쇼핑, ...]
거래 설명: "스타벅스 아메리카노"
거래 금액: 4500원
거래 유형: EXPENSE

위 정보를 바탕으로 가장 적절한 카테고리를 기존 목록에서 1~3개 추천해주세요.
JSON 형식: [{"categoryId": "...", "categoryName": "...", "confidence": 0.95}]
```

**성능 설계**:
- Claude API 호출: ~500ms (haiku 모델 사용 시)
- 캐싱: 동일 description → 동일 분류 결과 Caffeine 캐시 (1시간 TTL)
- 비동기: 사용자 입력 중 백그라운드 분류 (UI 차단 없음)

### E-2: 기능 간 연동 강화

**현재 미연동 항목 (6건)**:

| # | 연동 쌍 | 현재 | 구현 내용 |
|---|---------|------|----------|
| I-1 | 반복거래 → 예산 경고 | 반복거래 생성 시 예산 체크 없음 | 반복거래 생성 시 해당 카테고리 예산 잔여 확인 → 초과 시 경고 |
| I-2 | 카테고리그룹 ↔ 예산 | 그룹 단위 예산 조회 없음 | 그룹별 예산 집계 API |
| I-3 | 주간예산 ↔ 리포트 | 주간 예산 실적 리포트 미반영 | 월간 리포트에 주간 예산 달성률 포함 |
| I-4 | 결제수단 필터 | ✅ 이미 구현 | — |
| I-5 | 통계 ↔ 결제수단 | ✅ 이미 구현 | — |
| I-6 | 리포트 ↔ 알림 | 예산 초과 알림 없음 | 예산 80%/100% 도달 시 홈 배너 경고 |

**실제 구현 대상: I-1, I-3, I-6 (I-2는 복잡도 대비 가치 낮아 후순위)**

#### I-1: 반복거래 생성 시 예산 잔여 확인
- `RecurringTransactionExecutor.kt` — 거래 생성 시 해당 카테고리 월 예산 체크
- 예산 초과 시 거래는 생성하되, 로그 기록 + 알림 플래그

#### I-3: 주간예산 달성률 리포트 포함
- `ReportService.kt` — getMonthlyReport에 주간 예산 달성률 섹션 추가
- FE 리포트 페이지에 주간 예산 달성률 차트 추가

#### I-6: 예산 임계값 경고 (홈 배너)
- `DashboardBloc` — 대시보드 로드 시 예산 사용률 계산
- 80% 이상: 노란색 경고 배너, 100% 이상: 빨간색 경고 배너
- `dashboard_page.dart` — 상단에 경고 배너 표시

### E-3: 거래 일괄 편집

**설계**:
```
[거래 목록]
  → 길게 누르기(long press) → 다중 선택 모드 진입
  → 체크박스로 여러 거래 선택
  → 하단 액션바: [카테고리 변경] [결제수단 변경] [삭제]
  → 일괄 처리 후 목록 새로고침
```

**BE 구현**:
- `TransactionController.kt` — `PATCH /api/v1/transactions/batch`
- `TransactionDtos.kt` — `BatchUpdateRequest(ids: List<UUID>, categoryId?, paymentMethodId?)`
- `TransactionService.kt` — `batchUpdate()` 메서드

**FE 구현**:
- `transaction_list_page.dart` — 다중 선택 모드 (long press 진입, AppBar 변경)
- `transaction_bloc.dart` — `BatchUpdateTransactions` 이벤트
- 하단 액션바 위젯

### E-4: 월별 자동 요약 리포트

**설계**:
```
[스케줄러] 매월 1일 오전 9시
  → 지난달 MonthlyReport 생성
  → 요약 텍스트 자동 생성 (총 수입/지출/잔액, 최다 카테고리, 전월 대비)
  → ReleaseNote 또는 Announcement로 자동 등록
  → 홈 배너에 "3월 가계부 요약이 도착했습니다!" 표시
```

**BE 구현**:
- `MonthlyReportScheduler.kt` — `@Scheduled(cron = "0 0 9 1 * *")`
- `ReportService.kt` — `generateMonthlySummaryText()` — 주요 지표 텍스트 포맷
- `AnnouncementService`에 자동 공지 생성 연동

**FE 구현**:
- 기존 공지사항 배너 + 업데이트 탭으로 자연스럽게 표시 (추가 UI 없음)

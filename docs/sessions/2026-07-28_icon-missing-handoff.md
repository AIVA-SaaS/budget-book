## 1. 서버 쪽은 결백하다 (측정 완료 — 다시 확인하지 말 것)

- 라이브 폰트 `/assets/fonts/MaterialIcons-Regular.otf`
  - `cache-control: no-cache, must-revalidate` (immutable 제거됨, PR #277)
  - cmap 293 글리프, **로컬 빌드 산출물과 완전히 동일**(차집합 0)
  - `fact_check`(0xe256, 뷰 토글 3번째), `check_circle`(0xe159, 배지),
    `verified`(0xe699), `swap_horiz`(0xe625) **전부 존재**
- 해시 없는 산출물 8종 전부 `no-cache` (`infra/scripts/verify-cache-headers.sh` 통과)
- `index.html` 에 옛 Service Worker 강제 unregister + CacheStorage 삭제 스크립트가
  이미 있다(회차 12, 같은 계열 사고의 1회차 대응)
- 뷰 토글은 `UnifiedFilterBar.trailing` 에 고정 배치되고 chip 영역만 스크롤되므로
  레이아웃 클리핑 가능성도 낮다 (`unified_filter_bar.dart:155-199`)

→ **남은 원인은 클라이언트 상태이거나, 사용자가 말하는 "정산 아이콘" 이 내가 고친 것과
다른 대상이다.** 이 둘을 가르지 않고 또 고치면 3번째 추측 fix가 된다.

## 2. 사용자에게 받아야 할 증거 (이게 있어야 수정 착수)

1. **어느 화면의 무엇인가** — 스크린샷 1장이면 가장 빠르다.
   - (a) 거래 탭 상단 뷰 토글의 3번째 칸이 비어 있다 → 아이콘 폰트 문제
   - (b) 토글에 3번째 칸 자체가 없다 → 레이아웃/버전 문제
   - (c) 거래 타일의 정산 배지가 안 보인다 → **정산 스냅샷이 0건이면 정상**
     (라이브 `reconciliations` 테이블 0행 확인됨 — 정산을 한 번 만들어야 배지가 생긴다)
   - (d) 다른 화면의 다른 아이콘
2. **환경** — 웹/모바일, 브라우저, 하드 리프레시 여부
3. 웹이면 DevTools Network 에서 `MaterialIcons-Regular.otf` 응답 크기
   (37,276 B = 최신 / 그보다 작거나 `(disk cache)` = 구버전 물고 있음)

## 3. 증거별 수정안 (미리 정해 둠 — 받는 즉시 1회 적용)

- (a) 폰트가 구버전 → 클라이언트 캐시. 서버는 더 할 게 없다.
  **대응: 아이콘 폰트에 의존하지 않게 만든다** — 뷰 토글 3번째 세그먼트에 텍스트 라벨
  `정산` 추가(현재 아이콘 전용). 폰트가 실패해도 기능이 보인다. 배지는 이미 `N차` 텍스트를
  동반하므로 추가 조치 불필요.
- (b) 3번째 칸 부재 → 번들이 구버전. `main.dart.js` last-modified 와 `전체 선택`
  문자열(이스케이프 `전체 선택`) 존재 여부로 판정.
- (c) 배지 미노출 & 스냅샷 0건 → 버그 아님. 정산을 만들어 확인하도록 안내.
- (d) 대상 확인 후 재분류.
